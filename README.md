# Iris Flower Classification

## Project Overview
This project builds a Multi-Class Classification Pipeline using the Iris dataset.

## Models Used
- Logistic Regression
- Decision Tree Classifier

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the Iris dataset.
2. Perform data analysis.
3. Split the dataset into training and testing sets (80:20).
4. Apply feature scaling.
5. Train Logistic Regression and Decision Tree models.
6. Evaluate model performance.
7. Visualize confusion matrices and decision boundaries.

## Output
The project displays model accuracy, classification reports, confusion matrices, and a decision boundary visualization.

## Files
- `iris_classification.py` – Python source code.
- `iris_classification.ipynb` – Jupyter Notebook with code and outputs.
